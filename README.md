# 🏮 ศาลเจ้าแห่งโชคลาภ (Lucky Shrine)

เว็บ **เซียมซี ไพ่ยิปซี เลขมงคล และสะเดาะเคราะห์ออนไลน์** — เขียนใหม่เป็น React + TypeScript + Vite พร้อมแกนประมวลผลความเร็วสูง WebAssembly

- **Frontend:** React 19, TypeScript, Vite — UI ธีมจีน-ไทย, อนิเมชัน 3 มิติ, ไพ่ยิปซี, กระบอกเซียมซี, จุดเทียน, ลอยโคม, แก้ปีชง, สแกนภาพ/ลายเซ็น, ธีมเทศกาลอัตโนมัติ
- **Core Engine:** WebAssembly (`wasm/core.c` คอมไพล์เป็น `public/wasm/core.wasm` พร้อม fallback ฝังในชุดคำสั่ง)
- **ประมวลผลในเครื่อง 100%:** ข้อมูลทั้งหมดประมวลผลบนเครื่องของผู้ใช้ ไม่มีการส่งข้อมูลส่วนตัวออกนอกเครื่อง

> ⚠️ **เพื่อความบันเทิงเท่านั้น:** เลขมงคลไม่ใช่การทำนายผลสลากจริง และคำทำนายไม่ใช่คำแนะนำทางการแพทย์ กฎหมาย หรือการเงิน

## ฟังก์ชันและพิธีกรรม

1. **เซียมซี (Siamese Sticks):** จำลองกระบอกเซียมซี 3D เขย่าด้วยการกดปุ่ม ลากเมาส์ หรือเขย่ามือถือ มีมาตรวัดแรงสุ่ม และคำทำนาย 28 ใบ ครอบคลุม 4 ด้าน (การเงิน, ความรัก, สุขภาพ, การงาน)
2. **ไพ่ยิปซี (Tarot):** ไพ่ Major Arcana 22 ใบ พร้อมอนิเมชันพลิกไพ่ 3 มิติ เลือกเปิดได้ทั้ง 1 ใบ (ประจำวัน), 3 ใบ (อดีต-ปัจจุบัน-อนาคต) และ 5 ใบ รองรับไพ่กลับหัวและความหมายครบถ้วน
3. **เลขมงคลประจำตัว (Lucky Numbers):** คำนวณจากชื่อ ปีเกิด นักษัตร และวันที่ พร้อมอนิเมชันลูกล้อตัวเลขหมุนแบบเรียลไทม์
4. **สะเดาะเคราะห์ออนไลน์ (Rituals):**
   - **จุดเทียนต่อดวง:** แตะค้าง 4 วินาทีเพื่อจุดเปลวไฟและรัศมีแสง ปลดล็อกบทสวดและเลขมงคล
   - **ลอยโคมสะเดาะเคราะห์:** ปล่อยโคมลอยขึ้นสู่ท้องฟ้า พร้อมระบบดูแลจิตใจเชื่อมสายด่วน 1323
   - **แก้ปีชง:** วิเคราะห์ความสัมพันธ์ปีเกิดกับปีปัจจุบัน (ชง, ไห่, พัง, ตรง) พร้อมยันต์เรืองแสงและวิธีปฏิบัติตน
5. **สแกนดวงชะตา (Fortune Scan):** สแกนใบหน้า/ลายมือแบบประมวลผลในเครื่อง และกระดานเซ็นชื่อวิเคราะห์ลายเซ็น
6. **เทศกาล (Festivals):** สลับตามวันที่อัตโนมัติ หรือเลือกเปลี่ยนธีมเองได้ (ศาลเจ้าปกติ, สงกรานต์, ฮาโลวีน, ลอยกระทง, ตรุษจีน, ปีใหม่พร้อมจุดพลุ)

## การพัฒนาและรันเซิร์ฟเวอร์

```bash
# ติดตั้ง dependencies
npm install

# เริ่มต้น dev server
npm run dev

# คอมไพล์โปรเจกต์
npm run build
```
